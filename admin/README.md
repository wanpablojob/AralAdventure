# AralAdventure Admin Dashboard

This is the teacher/admin dashboard for AralAdventure. It reads synced student progress from Supabase.

## Environment variables

```env
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
```

## Local development

```bash
npm install
npm run dev
```

## Vercel deployment

Do not deploy this dashboard until the Vercel phase is approved. When approved, connect this folder to Vercel and add the same environment variables.
